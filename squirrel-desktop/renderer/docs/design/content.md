## UI 文案

- 动作用动词：「添加订阅」「重置」，避免空话。
- 空态写清**为什么空**和**下一步**。
- 错误写清**发生了什么**和**怎么恢复**（重试 / 检查登录 / 看日志）。
- 状态不单靠颜色：配合文字或图标。

## 示例方向

| 场景 | 差 | 好 |
|------|----|----|
| 空筛选结果 | 暂无数据 | 没有符合条件的视频。试试清空筛选。 |
| 连接失败 | 出错了 | 无法连接服务器。检查地址后重试。 |
| 主行动 | 确定 | 保存 / 添加订阅 |
