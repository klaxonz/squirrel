## 产品

自托管多站视频订阅中枢：订阅 → 同步入库 → 浏览整理 → 播放；附带 RSS、音乐与运维。  
能力清单见仓库根 [README](../../../../README.md)。

---

## 立场

1. **允许 redesign** 布局、密度、控件气质；现有 UI 是实现现状，不是终点。
2. **真源在代码**：`shared/styles/**`、`shared/ui/**`、壳与页面组件。
3. **外部产品只借结构/工作流**，不要混多套皮肤。
4. **不要**用已删除的长篇 design system / 旧审计报告挡合理改动。
5. **不使用带皮肤的 UI 组件框架**；基础控件由 `shared/ui` 统一实现，复杂无障碍交互只使用 headless primitives。

---

## 底线（产品，不是视觉教条）

| | |
|--|--|
| 内容与真实状态优先 | 空/错要诚实，装饰不抢内容 |
| 状态闭环 | loading / empty / error + 可执行下一步 |
| 意图可预期 | 主行动、危险、选中全站同一套表达（token 可改） |
| 系统先于特例 | 扩展 `shared/ui`，业务页不私建第二套控件 |

## 认证入口（2026-07）

**Workbench connection · 工作台连接面**：

- 认证是进入媒体工作台的连接状态，不是独立的品牌海报或营销落地页
- 登录、注册与服务器配置共享“服务器 → 账户 → 工作台”的真实流程上下文
- 入口沿用应用的同色表面、细边界、圆角与控件语言；不另建认证专属皮肤
- 服务器地址是登录上下文；地址已保存不冒充服务健康，健康状态必须来自真实测试
- 全局 `auth-entry.css` **禁止 `:deep()`**；控件像素仍由 `shared/ui` 统一拥有
- `AuthTitleBar` 仅负责窗控；每屏唯一 solid 橙色 CTA
- **禁止**：产品宣言大字、装饰编号、英文副标、营销左右屏、背景大图、玻璃卡、假数据面板

## 应用工作台（2026-07）

**Quiet Media Workbench · 安静媒体工作台**：

- 归仓是个人媒体资产工作台：先服务扫描、筛选、状态识别、连续播放与整理，再表达品牌
- 认证入口与应用共享工作台气质；进入应用后继续保持克制的信息层级
- 壳层使用低干扰的同色导航、内容画布与按需详情检查器；边界来自层级、间距和细分隔线，不来自灰色侧栏底板
- 消费页面使用内容画布 + 按需检查器，整理页面使用集合列表 + 内容区，系统页面使用工具栏 + 表格/设置行；只有播放器可以沉浸
- 媒体图像是主要视觉，橙色只表示播放、进度、选中与关键操作；常驻控件保持中性
- 集合、来源、状态与保存筛选属于同一导航模型；搜索、筛选、排序和密度靠近当前内容
- 网格与详细列表共享数据、分页和互动，只改变阅读密度；显示偏好可按集合记忆
- 视频卡片单击、双击或键盘确认均直接进入播放；头像、来源和卡片内快捷操作保留各自行为；批量操作仅在显式批量模式中出现
- 首页是“继续观看 + 统一收件箱”，不做 Dashboard；保留浏览位置，优先呈现真实更新与未完成内容
- 音乐迷你播放器在展开侧栏中停靠于设置上方；侧栏收起时原位保留封面与播放/暂停，不浮到内容区
- 视频库是可调密度的资产画布；观看记录和最近入库按时间自然分组；远端结果明确来源且不冒充本地资产
- **禁止**：媒体中心横向货架、传统 SaaS 卡片 Dashboard、六列等权缩略图墙、编辑刊物版式、装饰性英文、悬浮玻璃与大面积渐变
