# Typography

← [Foundations](./README.md)

**代码：** `src/shared/styles/layout.css`（`--app-h1-*` 等）

## 字体

| 角色 | 字体 |
|------|------|
| UI | Inter + 系统 fallback（`--font-sans`） |
| 等宽 | JetBrains Mono（`.app-mono`：日志、ID、计数） |

只用字号 / 字重 / 对比分层，不引入第二套展示字体。

## 字阶

| 级别 | 规格 | 场景 |
|------|------|------|
| Hero | 1.75rem / 650 | 登录、空态主标题（极少） |
| H1 | 1.6875rem / 600 | 页标题 |
| H2 | 1.25rem / 600 | 分组 |
| H3 | 1.0625rem / 600 | 卡片 / 模块标题 |
| H4 | 0.875rem / 600 | 紧凑标题 |
| Body | 0.875rem / 400–500 | 正文、列表 |
| Label | 0.75–0.8125rem / 500–600 | 侧栏、按钮、Tab、字段标签 |
| Micro | 0.625–0.6875rem / 500–600 | 角标、次要元数据 |

## 规则

- 固定 rem，不做流体大标题。
- 同一工具栏 ≤ 两档字号。
- 筛选字段标签：`0.6875rem / 600`。
- 筛选面板标题：`0.8125rem / 650`。
