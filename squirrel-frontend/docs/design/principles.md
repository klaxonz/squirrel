# Principles

← [目录](./README.md)

四条，全部可落地；气质形容词不单独成规。

## 1. 媒体与任务优先

缩略图、标题、状态、下一步动作压过 chrome。  
界面是**桌面运营台**，不是流媒体海报或 SaaS 仪表盘。

## 2. 一种语言

先复用 `shared/ui` 与 layout 模式，再扩展系统。  
禁止业务页平行造第二套按钮 / 筛选 / 空态。

## 3. 颜色表达意图，不装饰

品牌琥珀只服务主行动 / 焦点 / 播放 / 徽章。  
**选中、已筛选、导航当前 = 中性 ink，不是品牌色。**  
运维健康用语义色，不用 primary。

→ [Color](./foundations/color.md)

## 4. 状态说真话

加载、空、错、鉴权、runtime 必须可辨可操作。  
禁止用装饰或假 UI 掩盖失败。

→ [States pattern](./patterns/states.md) · [Content](./content.md)
