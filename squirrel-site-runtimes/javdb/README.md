JavDB Plugin
============

Runtime V2 plugin package for JavDB crawling with `squirrel-sdk`.

Capabilities
------------

- `check_login_status`
- `import_subscriptions`
- `resolve_subscription`
- `sync_subscription`
- `extract_video`
- `resolve_proxy_config`
- `rewrite_proxy_playlist`

Install in a development environment:

```bash
pip install -e ./squirrel-site-runtimes/javdb
```
