# 设计规范：赛博工业风采集中心 (Cyber-Industrial Sync Center)

## 1. 概述 (Overview)
重新设计采集中心 (Sync Center) 的 UI/UX，旨在消除过度卡片化、减少冗余文案、优化配色，并建立一套符合项目整体极简风格但更具“精密感”和“酷”视觉冲击力的界面。

### 核心理念
*   **去卡片化 (De-cardification)**：使用透明度、细边框和间距代替厚重的容器。
*   **精密排版 (Precision Layout)**：借鉴工业控制面板，强调数据对齐和直角线条。
*   **动态反馈 (Dynamic Feedback)**：通过 LED 呼吸灯和能量条动效增强实时运行感。

---

## 2. 视觉语言 (Visual Language)

### 配色方案 (Palette)
*   **背景 (Background)**: `#050505` (深空黑)。
*   **主色 (Primary)**: `#FF4F00` (国际橙) —— 用于核心操作和进度高亮。
*   **状态色 (Status LEDs)**:
    *   **排队中**: `#00E5FF` (冰青色) —— `glow-cyan` 效果。
    *   **执行中**: `#FFB300` (琥珀金) —— `glow-amber` 效果。
    *   **已完成**: `#00FF41` (黑客绿) —— `glow-green` 效果。
*   **中性色**:
    *   边框: `white/10` 或 `white/5`。
    *   次要文字: `white/40`。

### 字体与装饰 (Typography & Decoration)
*   **数字**: 关键指标使用 **点阵风格字体 (Dot Matrix)** 或等宽字体 (`font-mono`)。
*   **直角**: 放弃圆角，采用 **2px 微圆角或完全直角**。
*   **LED 状态灯**: 3px 小圆点，带 `box-shadow` 发光效果。

---

## 3. 组件细节 (Component Details)

### 3.1 三栏流水线 (Three-Lane Pipeline)
保持横向三栏布局，但大幅精简每行内容。

#### Lane 01: 待命队列 (Queue)
*   **标识**: 左侧显示点阵排位号（如 `#01`）。
*   **指示**: 冰青色 LED 灯微弱呼吸。
*   **内容**: `[站点图标] [订阅名称] [模式] [预计时间]`。

#### Lane 02: 活跃执行 (Active)
*   **标识**: 琥珀金 LED 灯快速闪烁。
*   **能量条 (Power Bar)**: 由 10-12 个独立方块组成的离散进度条。
*   **指标**: 大号点阵数字显示 `FOUND` 和 `SYNCED`。
*   **动效**: 边框随进度有琥珀色微光流动。

#### Lane 03: 近期完成 (Done)
*   **标识**: 静态绿色 LED 灯（或 `[✓]` 符号）。
*   **内容**: 类似系统日志的单行展示，包含 `[站点] [名称] [完成时间]`。

---

## 4. 交互与动效 (Interactions & Motion)

### 状态流转
*   **水平滑入**: 任务从左侧栏向右侧栏移动时，伴随 `translateX` 动画。
*   **亮度渐变**: 活跃任务的透明度为 100%，非活跃状态为 60%-80%。

### 悬浮反馈
*   **行高亮**: 鼠标悬浮时，边框色从 `white/10` 变为 `white/30`。
*   **操作显现**: 悬浮时在行末尾淡入“查看详情”按钮（国际橙色描边）。

---

## 5. 技术实现 (Implementation)
*   **框架**: Vue 3 SFC (`<script setup>`)。
*   **样式**: Tailwind CSS + 自定义 CSS 变量。
*   **动效**: CSS Transitions + Tailwind `animate-pulse` (自定义呼吸逻辑)。
*   **图标**: 继续使用现有的 Heroicons 或 Lucide。
