# 设计规范：丝滑科幻风无边界流水线 (Fluid Sci-Fi Borderless Pipeline)

## 1. 概述 (Overview)
这是采集中心的第二次重构，旨在彻底打破“卡片化”视觉限制。通过移除显性的容器边界，利用发光线条、激光扫描动效和流体化数据展示，营造一种数据在开放空间中流动的“未来控制台”感。

### 核心理念
*   **无边界化 (Borderless)**：取消所有列和行的显性背景与边框。
*   **动效结构 (Motion as Structure)**：用动态线条和悬浮光效暗示空间区域。
*   **流体质感 (Fluidity)**：采用柔和的辉光 (Glow)、波形进度条和顺滑的位移轨迹。

---

## 2. 视觉语言 (Visual Language)

### 配色方案 (Palette - OKLCH)
*   **背景**: `#050505` (纯净深黑)。
*   **导轨线 (Rails)**: `oklch(70% 0.15 200 / 0.1)` (冰蓝微光)。
*   **扫描光 (Scanline)**: `oklch(80% 0.2 40)` (国际橙强光)。
*   **状态辉光**:
    - PENDING: `oklch(70% 0.1 200)` (冰青)。
    - ACTIVE: `oklch(75% 0.15 60)` (琥珀)。
    - FINISHED: `oklch(75% 0.2 150)` (翠绿)。

### 装饰元素 (Decor)
*   **背景编号**: 在每列底部或背景中心放置巨型数字 (01, 02, 03)，使用 `font-black`, `opacity-[0.03]`。
*   **粒子底纹**: 极其细微的动态粒子或网格，仅在活跃区域显现。

---

## 3. 组件重构细节 (Component Redesign)

### 3.1 布局架构
*   移除 `board-shell`。
*   三栏之间仅由一条从顶到底的、带呼吸感的**垂直能量线**分隔。
*   标题侧旋 90 度或以极简的 `[ 01 / QUEUE ]` 形式置于顶部。

### 3.2 任务项 (Data Items)
*   **常态**: 纯文字+图标，无背景，间距适中。
*   **悬浮 (Hover)**: 
    - 触发 **“激光扫描”**：一条 2px 宽的高亮光带从左至右快速滑过。
    - 背景淡入极其微弱的 `backdrop-blur` 和 `bg-white/5`。
    - 整体向右微移 4px。

### 3.3 活跃执行 (Lane 02)
*   **进度展示**: 取消方块进度条，改为一条**发光的正弦波形图**或**流动的能量束**。
*   **数据跳动**: 数字在更新时伴随微小的缩放动效。

---

## 4. 交互与动效 (Interactions)

### 任务流转 (Travel)
*   项目从一栏移动到另一栏时，不再是简单的消失/出现，而是沿着水平路径“滑行”过去，并伴随 `blur` 滤镜产生的运动模糊。

### 全局呼吸
*   非活跃项保持 40% 透明度，活跃项 100%。

---

## 5. 技术方案
*   **CSS**: 使用 `mask-image` 实现扫描线边缘羽化。
*   **Animation**: 使用 `framer-motion` 风格的 Vue Transitions (或原生 CSS Keyframes)。
*   **SVG**: 用于绘制连接各栏的动态导轨。
